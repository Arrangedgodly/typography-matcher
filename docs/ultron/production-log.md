## T04 · F · Font-loading engine — awaiting-approval

**Delegation:** worker subagent, dispatched 2026-08-28 by production-supreme (dispatch 4 of the run). Implementation follows the committed R2 recommendation (Option A) and its "Implementation consequences" API sketch exactly — no re-litigation.

**Changed files:**
- `src/lib/fontLoader.ts` — new. The font-loading engine per R2:
  - `buildCss2Url(p)` — pure builder: families in pairing order as repeated `family=` params, spaces → `+`, axes alphabetical (`ital,wght`), `ital` axis only when `italic: true`, tuples grouped upright-then-italic with weights ascending + deduped (lexicographic tuple order, matches T02's live-verified `Crimson+Pro:ital,wght@0,400;0,600;1,400;1,600`), always `display=block`.

Default timeout 4000 ms (`DEFAULT_FONT_LOAD_TIMEOUT_MS`); default sample text = latin probe + the essay's typographic punctuation (`DEFAULT_FONT_SAMPLE_TEXT`). Rejects with typed `FontLoadError` carrying machine-readable `reason` ∈ `css | timeout | network | no-face`; every failure path removes the pending link.
