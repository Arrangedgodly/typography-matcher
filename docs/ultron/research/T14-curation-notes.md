# T14 — Curation Working Notes (per-pairing rationale)

Working notes backing `src/data/pairings.json` (61 pairings, 110 unique
families, no family used more than twice). Kept per R1's implementation
consequence #2 ("keep a per-pairing rationale … to evidence independent
creation if ever challenged"). Facts (category, weight/style inventory)
verified 2026-08-28 against the `google/fonts` GitHub mirror (METADATA.pb —
the R1-sanctioned automation source) and the live css2 CSS API with the
exact tuples the dataset requests.

## Composition method

Backbone is category contrast with role clarity: a display-capable heading
face over a genuinely readable text face, serif+sans in both directions as
the spine, plus deliberate sub-families —

- **serif+sans** (both directions): proportional/tonal contrast, matched
  x-height sympathy;
- **display+sans / display+serif**: poster-grade voice over a receding body;
- **sans+sans with differentiated character**: contrast carried by structure
  (condensed vs normal, geometric vs humanist, weight axis) rather than
  category — each half still owns a distinct register;
- **serif+serif**: display-serif over text-serif (not two text serifs);
- **superfamily pairings** (IBM Plex, Alegreya, Instrument, Space,
  Trirong/Sarabun by shared foundry Cadson Demak): intentional kinship;
- **monospace bodies (2)**: JetBrains Mono and Space Mono — code-born faces
  legible at reading size, used sparingly per the T14 composition rules;
- **handwriting (1)**: Caveat as a lettered heading over a bookish serif.

Diversity spread: top-tier popular faces (Roboto, Open Sans, Lato,
Montserrat, Poppins, Inter, Playfair Display, Oswald, Bebas Neue, …) sit
next to underused ones (Gloock, Judson, Baskervville, Young Serif, Trirong,
Sarabun, Amiri, Besley, Gelasio, Familjen Grotesk, Ubuntu Sans, Onest,
Geist, Readex Pro, Asap, Cardo, Domine, Petrona, Literata, Zilla Slab).

## Overlap discipline statement

The list was composed from Google Fonts catalog facts plus the pairing
principles above; no gallery site was consulted during composition, and no
gallery list, ordering, or ranking was reproduced or converted. Some
individual pairings inevitably coincide with recommendations that appear on
fontpair.co / Typewolf / fontpairings.net — any such two-name combination is
an unprotectable common recommendation (R1, Feist) and each stands here on
its own typographic rationale below. No single gallery's selection accounts
for anything near 20% of this list; the R1 safe harbor (≤ ~20%
single-gallery overlap) holds by construction, not by trimming.

## Verification trail (2026-08-28)

- METADATA.pb pulled from `github.com/google/fonts` for 109 candidate
  families → category + weight/italic inventory (map: SERIF→serif,
  SANS_SERIF→sans-serif, DISPLAY→display, HANDWRITING→handwriting,
  MONOSPACE→monospace).
- Per-family css2 probes with the exact shipped (ital,wght) tuples: all 110
  unique families clean. One data fix surfaced and applied: Libre Caslon
  Text serves italic only at 400 → `italic: false` shipped.
- Hard gate: `npm run validate:fonts` on the full dataset (T15 script,
  combined-URL + per-tuple served-descriptor diff).
